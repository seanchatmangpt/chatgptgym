# Gym Maturity 5x7

This repository uses a five-plane, seven-level maturity model. The contract is evaluation-only and does not authorize real-world side effects.

| Plane | M0 Seed | M1 Modeled | M2 Admitted | M3 Runnable | M4 Receipted | M5 Replayable | M6 Enterprise |
|---|---|---|---|---|---|---|---|
| Semantics | idea only | named vocabulary | machine-readable schema | validated scenarios | versioned provenance | cross-gym mappings | federated canonical graph |
| Evaluation | manual examples | documented tasks | deterministic tasks and metrics | executable benchmark | adversarial portfolios | adaptive curriculum | continuous league evaluation |
| Runtime & safety | no runtime | mock path | offline sandbox and typed refusals | exact-subject simulation | bounded state transitions | isolated policy envelopes | federated governed runtime |
| Evidence & replay | claims only | logs | structured observations | verifier output | deterministic receipts | replay equivalence | signed evidence DAG |
| Operations | ad hoc | documented setup | pinned toolchain | automated local gate | CI artifacts | release and regression gates | SLO, security, interoperability |

The overall maturity level is the minimum level achieved across all five planes. Documentation, a workflow, or a receipt alone cannot crown the gym.
